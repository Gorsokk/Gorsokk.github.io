## Mettre en ligne gratuitement (GitHub Pages)
1. Sur GitHub, créer un dépôt public nommé exactement `Gorsokk.github.io`.
2. Téléverser le contenu de ce dossier (`index.html`, le dossier `demo-receptionniste`, ce README) : « Add file » → « Upload files ».
3. Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)` → Save.
4. Après 1 à 2 minutes, le site est en ligne : https://gorsokk.github.io (démo : https://gorsokk.github.io/demo-receptionniste/).
5. Ajouter ce lien : profil GitHub, README de osrs-toolkit, profil Fiverr (description), panneau Twitch, candidatures.
